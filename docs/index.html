Build custom Android ROMs
from stock firmware

LtiRom Studio is a free desktop app for Windows. Import a firmware archive, remove the apps you don't want, apply mods, and get a signed flashable zip or A/B OTA. Every step runs for real in WSL, and you can see and check each one.

Why LtiRom Studio

Building a ROM by hand means juggling dozens of tools and hoping the result boots. LtiRom Studio turns that into a guided workflow that checks your work before it builds.

One place for the whole build

From the stock firmware archive to the signed package and the GitHub release.

Will it build?

Runs the build's own checks against your settings in seconds, and most problems come with a one-click fix.

Safe by default

Refuses a tree that would not boot: missing permissions or SELinux labels, broken links, unsigned apps, a full super partition.

Debloat with care

Every app's name, icon, signer and what relies on it; the last home screen, keyboard or camera can't be removed.

Mods in Kotlin

A typed SDK for file, property, smali and resource edits, checked against the firmware before a build.

Fast rebuilds

Unchanged stages and images come from cache: a rebuild with no changes takes about 90 seconds.

The ROM pipeline

Eight stages, each cached by its inputs. Run the whole build or stop after any stage.

  1. AcquireDownload or import the stock firmware and check its SHA-256.
  2. Extractzip, 7z, payload.bin, sparse, block OTA and Odin; EROFS, ext4 and F2FS images.
  3. AssembleWork tree, boot images, mount tables and build properties.
  4. DebloatRemove the apps you pick, after checking what the device still needs.
  5. Patches & modsInstalled Kotlin mods and your own scripts.
  6. Build & signPartition images and super, the signed boot chain, flashable zip and A/B OTA.
  7. Release metadataThe OTA manifest and a changelog drafted from the build.
  8. PublishLocal export or a GitHub release, after you confirm.

The package never contains firmware images (radio, bootloader) or vbmeta. Flashing the result is up to you.

A look inside

A professional, IDE-like workspace: dense where you work, calm everywhere else.

Get started

You need Windows 11 with WSL 2 and an Ubuntu LTS distribution, JDK 21, and the build service checked out next to the app.

LtiRomProject/
├── LtiRomGui/      (the app)
└── LtiRomServer/   (the build service that runs inside WSL)

./gradlew :lti-desktop:run

Setup checks WSL, installs the build service and builds every tool. Then create a workspace, import your firmware, press "Check now" under "Will it build?", and start the pipeline.
