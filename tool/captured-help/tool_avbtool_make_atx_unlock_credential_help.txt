usage: avbtool make_cert_unlock_credential [-h] [--output OUTPUT]
                                           --intermediate_key_certificate
                                           INTERMEDIATE_KEY_CERTIFICATE
                                           --unlock_key_certificate
                                           UNLOCK_KEY_CERTIFICATE
                                           [--challenge CHALLENGE]
                                           [--unlock_key UNLOCK_KEY]
                                           [--signing_helper APP]
                                           [--signing_helper_with_files APP]

options:
  -h, --help            show this help message and exit
  --output OUTPUT       Write credential to file
  --intermediate_key_certificate INTERMEDIATE_KEY_CERTIFICATE
                        Path to intermediate key certificate file
  --unlock_key_certificate UNLOCK_KEY_CERTIFICATE
                        Path to unlock key certificate file
  --challenge CHALLENGE
                        Path to the challenge to sign (optional). If this is
                        not provided the challenge signature field is omitted
                        and can be concatenated later.
  --unlock_key UNLOCK_KEY
                        Path to unlock key (optional). Must be provided if
                        using --challenge.
  --signing_helper APP  Path to helper used for signing
  --signing_helper_with_files APP
                        Path to helper used for signing using files
